# Archived in-plane NEMD workflow

This directory preserves a representative completed NEMD case, including its LAMMPS input, structure/potentials, energy exchange data, temperature profile, log, analysis script, and figures.

It is deliberately classified as **legacy/audited** because the transport direction is x while the input uses periodic x (`boundary p p f`). See `../../audit/KNOWN_LIMITATIONS.md` from the repository root before using these results.
